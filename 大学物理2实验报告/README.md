# 大学物理实验（2）资料整理

本仓库汇总大学物理实验（2）的实验报告、预习资料、数据表、图表、实验照片及数据处理工程，方便按实验项目查阅和学习。资料包含不同版本和不同时期的内容。报告中的数据、结论与格式应结合自己的实验记录和当期课程要求判断；参考资料不应直接代替个人实验报告。

## 快速开始

1. 在下面的实验导航中选择实验项目。
2. 专题资料不足时，可继续查阅历史资料合集。

## 目录结构

```text
.
├── README.md
├── 实验资料/             # 11 个专题；各专题 README 提供文件链接
├── 课程资料/             # 2021 年选课体验等课程相关资料
├── 历史资料/
│   └── 早期资料合集/     # 保留原合集目录和实验编号
├── docs/
│   ├── 文件索引.md       # 所有原始资料的完整导航
│   ├── 文件清单.csv      # 原路径、整理后路径、大小和 SHA-256
│   ├── 重复文件.md       # 内容完全相同的文件组
│   └── 整理说明.md
├── .gitignore
└── .gitattributes
```
